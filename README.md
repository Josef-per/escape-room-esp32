# Projeto em conjunto com o esp 32

  Esse projeto foi desenvolvido como uma escape room, tendo inspirações na mecânica do jogo eletrônico " welcome to the game ", sendo o objetivo encontrar uma sequencia de cores pelo site, a sequencia vai ser enviada pelo esp e validada novamente no site, caso correta avança para a próxima etapa do jogo.

  Projeto desenvolvido para realizações academicas, da matéria de SEMB.
